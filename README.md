# Mureka API Articles framework

Standalone static website. Open index.html directly or upload this directory to any static host (Cloudflare Pages, Netlify, Vercel, S3, or Nginx). No build command or dependencies are required; publish directory is `.`.

This is an editorial framework preview, not a published content library. Article headings are selected from the supplied document; article bodies and FAQ answers are placeholders. The supplied document's instructions are not deployment instructions. Search and categories work locally, with article detail previews available from every article.

Files: index.html (page structure), styles.css (responsive styles), app.js (sample catalog and interactions).

Before public launch: replace placeholders with approved articles and verified FAQ; generate permanent static URLs for individual articles and categories; add canonical URLs, sitemap.xml, robots.txt, RSS, Open Graph metadata and Article/BreadcrumbList structured data using the final domain. Remove noindex only after those steps. FAQ structured data should reflect visible approved answers and does not guarantee rich results or AI citations.

Fonts load optionally from Google Fonts with local system fallbacks. No analytics, tracking, subscription service, or backend is configured.
